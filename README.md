## 📋 OVERVIEW / ОБЗОР

**[EN]** **MDRG Custom Room** is a comprehensive artist toolkit that unlocks full control over all 21 visual nodes in the player's bedroom. Every furniture piece, decoration, lighting element, and door is available as a purchasable item in **Lady Annalie's Clothier Shop**.

This mod is designed for **artists, texture creators, and customizers** who want to personalize their room environment with custom artwork, transparent overlays, or complete visual overhauls.

**Key Features:**
- ✅ **21 Fully Customizable Nodes** — Every element in the room can be replaced with your own PNG textures.
- ✅ **Shop Integration** — All items are sold in Annalie's Clothier Shop for easy access.
- ✅ **Transparent Overlay Tool** — Hide any object instantly using the included transparent texture.
- ✅ **Pre-Configured Lighting Bypass** — `LightMultiply.png` and `MorningLight.png` are included and ready to use.
- ✅ **No MelonLoader Required** — Pure native Lua API, works on PC and Android.

**[RU]** **MDRG Custom Room** — это комплексный инструментарий для художников, который предоставляет полный контроль над всеми 21 визуальными нодами в спальне игрока. Каждый предмет мебели, декорация, элемент освещения и дверь доступны как покупаемые предметы в **магазине одежды Lady Annalie**.

Этот мод создан для **художников, создателей текстур и кастомизаторов**, которые хотят персонализировать окружение своей комнаты с помощью собственных PNG-текстур, прозрачных наложений или полного визуального обновления.

**Ключевые особенности:**
- ✅ **21 полностью кастомизируемая нода** — Каждый элемент в комнате может быть заменён вашими собственными PNG-текстурами.
- ✅ **Интеграция с магазином** — Все предметы продаются в магазине одежды Аннали для удобного доступа.
- ✅ **Инструмент прозрачного наложения** — Мгновенно скройте любой объект с помощью включённой прозрачной текстуры.
- ✅ **Пре-конфигурированный обход освещения** — `LightMultiply.png` и `MorningLight.png` включены и готовы к использованию.
- ✅ **Не требует MelonLoader** — Чистый нативный Lua API, работает на ПК и Android.

## 🎨 HOW TO HIDE OBJECTS / КАК СКРЫТЬ ОБЪЕКТЫ

**[EN]** The mod archive includes a special tool: `Alternative transparent texture for hiding the object.png`.

**To hide any object in the room:**
1. Rename the transparent texture to match the node name you want to hide.
2. Examples:
   - To hide the cupboard: rename to `cupboard.png`
   - To hide the bed: rename to `bed.png`
   - To hide the TV: rename to `TV.png`
   - To hide the rug: rename to `rug.png`
3. **Buy** the renamed file in Annalie's Clothier Shop and equip it.
4. The object will become completely invisible.

**[RU]** В архиве мода включён специальный инструмент: `Alternative transparent texture for hiding the object.png`.

**Чтобы скрыть любой объект в комнате:**
1. Переименуйте прозрачную текстуру в имя ноды, которую хотите скрыть.
2. Примеры:
   - Чтобы скрыть шкаф: переименуйте в `cupboard.png`
   - Чтобы скрыть кровать: переименуйте в `bed.png`
   - Чтобы скрыть телевизор: переименуйте в `TV.png`
   - Чтобы скрыть ковёр: переименуйте в `rug.png`
3. **Купите** переименованный файл в магазине одежды Аннали и экипируйте его.
4. Объект станет полностью невидимым.

## 💡 LIGHTING SYSTEM MECHANICS / МЕХАНИКА СИСТЕМЫ ОСВЕЩЕНИЯ

### [1] MORNING LIGHT — TIME-LOCKED NODE / УТРЕННИЙ СВЕТ — НОДА, ЗАБЛОКИРОВАННАЯ ПО ВРЕМЕНИ

**[EN]** The "Morning Light" node is bound to the game's internal time-of-day cycle.  
The engine activates this sprite **ONLY during morning hours (approx. 06:00–12:00)**.

⚠️ **CRITICAL BEHAVIOR:** During day or night, the item remains equipped but has **ZERO visual effect**. This is NOT a bug — it is hardcoded native game behavior.

**[RU]** Нода "Morning Light" привязана к внутреннему циклу времени суток игры.  
Движок активирует этот спрайт **ТОЛЬКО в утренние часы (примерно 06:00–12:00)**.

⚠️ **КРИТИЧЕСКОЕ ПОВЕДЕНИЕ:** Днём или ночью предмет остаётся экипированным, но имеет **НУЛЕВОЙ визуальный эффект**. Это НЕ баг — это захардкоженное нативное поведение игры.

---

### [2] WINDOW LIGHT (NODE "Light") — SUB-TEXTURE OVERLAY / СВЕТ ИЗ ОКНА (НОДА "Light") — НАЛОЖЕНИЕ ПОДТЕКСТУРЫ

**[EN]** The "Light" node (`/Room/Light`) is a sub-texture of the "Window" sprite.  
It renders as a small rectangular light beam that visually "pierces" through the main Window sprite, simulating sunlight breaking into the room.

**[RU]** Нода "Light" (`/Room/Light`) — это подтекстура спрайта "Window".  
Она рендерится как небольшой прямоугольный световой луч, который визуально "пронзает" основной спрайт окна, имитируя солнечный свет, проникающий в комнату.

---

### [3] LIGHT MULTIPLY — MASTER LIGHT CONTROLLER / LIGHT MULTIPLY — ГЛАВНЫЙ КОНТРОЛЛЕР ОСВЕЩЕНИЯ

**[EN]** The "Light Multiply" node is the **MASTER LIGHT** that governs ALL other lighting sources in the room, EXCEPT Morning Light (which is time-locked by the engine).

⚡ **KEY FUNCTION:** This node **NEUTRALIZES** the overall lighting level of the room. It acts as the primary brightness controller — whatever texture is applied here directly defines the final luminosity of the entire room.

🔓 **BYPASS METHOD (PRE-CONFIGURED):**  
To bypass the Morning Light time-lock and achieve perfectly uniform lighting 24/7, you only need TWO PNG files.

⚠️ **IMPORTANT:** Both required PNG files (`LightMultiply.png` and `MorningLight.png`) are **ALREADY INCLUDED** in the mod's archive. You do not need to create, copy, or rename them manually.

**HOW TO USE:**
1. The mod archive already contains two identical custom light textures.
2. One is pre-named `LightMultiply.png`.
3. The other is pre-named `MorningLight.png`.
4. Simply **buy** BOTH items in Annalie's Clothier Shop and equip BOTH.

✅ **RESULT:**
- The game applies the SAME custom texture as both the master light (Light Multiply) AND the morning light.
- Light Multiply neutralizes the engine's dynamic lighting, locking the brightness to your custom texture's luminosity.
- The time-lock on Morning Light is effectively neutralized.
- The lighting level is **ALWAYS IDENTICAL and STABLE 24 hours a day**, regardless of the in-game time cycle.

No engine tricks, no alpha textures, no code hacks — just using the game's own logic by feeding it the same texture through two slots.

**[RU]** Нода "Light Multiply" — это **ГЛАВНЫЙ СВЕТ**, который управляет ВСЕМИ другими источниками освещения в комнате, КРОМЕ Morning Light (который заблокирован по времени движком).

⚡ **КЛЮЧЕВАЯ ФУНКЦИЯ:** Эта нода **НЕЙТРАЛИЗУЕТ** общий уровень освещения комнаты. Она действует как главный контроллер яркости — любая текстура, применённая здесь, напрямую определяет финальную освещённость всей комнаты.

🔓 **МЕТОД ОБХОДА (ПРЕ-КОНФИГУРИРОВАННЫЙ):**  
Чтобы обойти временную блокировку Morning Light и достичь идеально равномерного освещения 24/7, вам нужны всего ДВА PNG-файла.

⚠️ **ВАЖНО:** Оба необходимых PNG-файла (`LightMultiply.png` и `MorningLight.png`) **УЖЕ ВКЛЮЧЕНЫ** в архив мода. Вам не нужно создавать, копировать или переименовывать их вручную.

**КАК ИСПОЛЬЗОВАТЬ:**
1. В архиве мода уже есть две идентичные кастомные текстуры света.
2. Одна предварительно названа `LightMultiply.png`.
3. Другая предварительно названа `MorningLight.png`.
4. Просто **купите** ОБА предмета в магазине одежды Аннали и экипируйте ОБА.

✅ **РЕЗУЛЬТАТ:**
- Игра применяет ОДНУ И ТУ ЖЕ кастомную текстуру как к главному свету (Light Multiply), так и к утреннему свету.
- Light Multiply нейтрализует динамическое освещение движка, фиксируя яркость на освещённости вашей кастомной текстуры.
- Временная блокировка Morning Light эффективно нейтрализована.
- Уровень освещения **ВСЕГДА ИДЕНТИЧНЫЙ И СТАБИЛЬНЫЙ 24 часа в сутки**, независимо от внутриигрового цикла времени.

Никаких трюков движка, никаких альфа-текстур, никаких хуков кода — просто использование собственной логики игры, подавая ей одну и ту же текстуру через два слота.

## 🔴 NOTABLE SIZES & ASPECT RATIOS / ПРИМЕЧАТЕЛЬНЫЕ РАЗМЕРЫ И СООТНОШЕНИЯ СТОРОН

**[EN]** 
- **Bathroom Door (126x1263)** — Exceptionally tall vertical sprite. Aspect ratio is approximately 1:10, which is unusual for Unity sprites. This is the original game asset size, not a modding error.
- **Bathroom Door Light (110x1148)** — Slightly narrower and shorter than the door. This is the light beam overlay that sits ON TOP of the door sprite. It is visible from the player's own room (NOT from a separate shower scene) whenever the bot Jun is showering alone. In all other game states, this node exists in the hierarchy but is not rendered.

**[RU]** 
- **Bathroom Door (126x1263)** — Исключительно высокий вертикальный спрайт. Соотношение сторон примерно 1:10, что необычно для спрайтов Unity. Это оригинальный размер ассета игры, а не ошибка моддинга.
- **Bathroom Door Light (110x1148)** — Чуть уже и короче двери. Это наложение светового луча, которое находится ПОВЕРХ спрайта двери. Оно видно из собственной комнаты игрока (НЕ из отдельной сцены душа), когда бот Джун принимает душ одна. Во всех других состояниях игры эта нода существует в иерархии, но не рендерится.

## 🔴 KNOWN LIMITATIONS / ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

**[EN]** 
- **Lightswitch (LightswitchOn)** is NOT included in this 21-node list. It is a UI element (`UnityEngine.UI.Image`) and requires direct C# DLL injection via MelonLoader, as `TextureOverriderManager` does not support Canvas UI sprites.
- **Morning Light** has zero effect outside morning hours — this is hardcoded game behavior, not a bug.

**[RU]** 
- **Lightswitch (LightswitchOn)** НЕ включён в этот список из 21 ноды. Это UI-элемент (`UnityEngine.UI.Image`), который требует прямой C# DLL-инъекции через MelonLoader, так как `TextureOverriderManager` не поддерживает Canvas UI-спрайты.
- **Morning Light** не имеет эффекта вне утренних часов — это захардкоженное поведение игры, а не баг.
